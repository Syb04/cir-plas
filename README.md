# CirPlas — CCP 装置向けプラズマ回路シミュレータ（仕様策定中）

ウェハ電極とフォーカスリング電極の 2 駆動電極を持つ CCP（容量結合プラズマ）装置を、
軸対称の等価回路メッシュとして **ngspice** で解き、定在波効果・表皮効果を含む
電子加熱分布と電子密度分布を計算するデスクトップツールです（Windows ネイティブ GUI）。
