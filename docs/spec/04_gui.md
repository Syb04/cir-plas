# 04. GUI 仕様

## 1. 設計方針

- **Windows ネイティブのデスクトップアプリ**（Qt 6 Widgets）。Web 技術は使いません。
- 単一メインウィンドウ＋ドックウィジェット構成。レイアウトはユーザが変更・保存可能。
- **UI スレッドは計算をしない**。解析はワーカプロセス、重い後処理（FFT、補間）はワーカまたはスレッドプール。
- 入力値は常に単位付きで表示し、派生量（面積、容量/面積、$\omega_{pe}$、$\delta$ など）を即時に表示して「入力の意味」を確認できるようにします。
- 日本語 / 英語の切り替え（Qt 翻訳）。**初期言語は日本語**（決定事項）。
- ライト / ダークテーマ。

## 2. 画面構成

```
┌──────────────────────────────────────────────────────────────────────────┐
│ メニュー / ツールバー（新規・開く・保存 | 実行(F5)・中止(Esc) | モード: AC/TRAN/SC/Sweep）│
├───────────────┬──────────────────────────────────────┬───────────────────┤
│ 設定ツリー      │  中央タブ                              │ プロパティ/派生量     │
│  ├ 幾何         │   [断面図・メッシュ] [ネットリスト]        │  選択項目の説明、     │
│  ├ プラズマ      │   [結果: 概要 | 径方向 | 2D | 波形 |      │  単位、妥当範囲、     │
│  ├ 回路         │          スペクトル | エッジ | 密度 |      │  関連する診断量       │
│  ├ 数値設定      │          比較 | スイープ]                │                   │
│  └ 出力         │                                      │                   │
├───────────────┴──────────────────────────────────────┴───────────────────┤
│ 実行ペイン：進捗バー、周期/反復ごとの収束プロット、ETA、ログ（フィルタ付き）、ラン履歴          │
└──────────────────────────────────────────────────────────────────────────┘
```

## 3. ワークフロー

1. 新規プロジェクト（テンプレート：代表 300 mm 構成 / 検証ケース / 空）。
2. 幾何 → プラズマ → 回路 → 数値設定を順に編集。各パネルは即時検証（赤枠＋メッセージ）。
3. **AC プレビュー**（< 1 s）で定在波プロファイル・PSR・推奨 $N_z$ を確認。
4. TRAN 実行。進捗と周期統計を監視。必要なら中止。
5. 結果タブで評価。比較タブで他のランと重ね描き。
6. スイープ（FR 容量、周波数、ギャップ …）を設定して並列実行、傾向を把握。
7. エクスポート（CSV/PNG/ネットリスト/レポート）。

## 4. パネル仕様

### 4.1 幾何パネル

| 項目 | 入力 | 備考 |
|---|---|---|
| 領域テーブル | 名前、外径 $r_{out}$、下部導体（W/F/G）、スタック（材料・厚さの行） | 行の追加・削除・並べ替え。隣接領域の連続性を自動チェック |
| ギャップ | 定数 / テーブル（r, l）/ 式（例：ガウス形シェイプト電極） | 右側にプロファイルのプレビュー |
| 上部構造 | 導体：接地 / 駆動（ポート T）、スタック | |
| 外周境界 | short / open / impedance（R, C） | |
| 断面図 | 色分けされた層・電極・ギャップ、メッシュ線（セル境界）、ホバーで寸法表示 | QGraphicsView。ズーム・パン |
| 派生量 | 各領域の面積、容量/面積、$C_{WF}$ 推定値 | |

### 4.2 プラズマパネル

| 項目 | 入力 |
|---|---|
| ガス・圧力・ガス温度 | DB から選択、Pa / mTorr 切替 |
| 電子密度 | モデル（一様 / 放物 / テーブル / ファイル / 自己無撞着）、$n_0$、$a$。プロファイルのプレビュー |
| 電子温度 | 自動（粒子バランス）/ 手動。自動時は計算値を表示 |
| シース | モデル（matrix / child）、$\alpha_{min}$、確率的加熱（hard-wall / off、$\kappa_{stoc}$）、シース内オーミック（on/off, $\kappa_{sh}$） |
| 衝突 | $\nu_m$ 自動 / 手動、$h_l$ 自動 / 手動 |
| 派生量 | $\omega_{pe}$、$f_{pe}$、$\lambda_D$、$\delta$、$\nu_m$、$u_B$、$\bar v_e$、$\omega_{PSR}$ 推定、$\lambda_{eff}$ 推定、$kR$、$\delta/(l_p/2)$、推奨 $N_z$ |

### 4.3 回路パネル

| 項目 | 入力 |
|---|---|
| ポート W / F / T | 電源テーブル（周波数、振幅、位相；電圧/電流/電力指定）、$C_b$、$L_{feed}$、$C_{stray}$ |
| FR 給電 | `esc_coupled`（既定。結合容量は幾何パネルのスタックから自動計算し、ここに表示）/ `separate`（独立電極：none / tie / cap_to_gnd / series_LC / coupling_to_W / dc_bias / source と値） |
| 電極間容量 $C_{WF}$ | `separate` 時のみ。自動 / 手動 |
| 上級：追加ネットリスト | 構文強調付きエディタ、Lint（禁止文・未定義ノード）、予約ノード名の説明 |
| ネットリストプレビュー | 生成結果の全文（読み取り専用、検索、行番号、セクション折りたたみ） |
| 簡易回路図 | ポートと外部回路要素の自動描画（ラダー全体は描かない） |

### 4.4 数値設定パネル

| 項目 | 入力 |
|---|---|
| メッシュ | 領域ごとの分割数、グレーディング比、$N_z$（推奨値ボタン）。セル幅のバーグラフ表示 |
| TRAN | `pts_per_cycle`、ランプ、最小/最大周期、測定窓、`pss_tol` |
| 自己バイアス | 方式（two_stage / scaled_cb_only）、$\kappa_b$、許容値 |
| 密度反復 | 有効化、緩和係数、許容値、最大反復、TRAN 補正の有無 |
| ngspice | オプションの上書き（上級）。既定値へのリセット |
| 見積り | 未知数、推定計算時間（直近のベンチマーク係数から） |

### 4.5 実行ペイン

- モード選択（AC / TRAN / SC / Sweep）、実行、中止、キュー表示（スイープ時の並列ジョブ）。
- 進捗：ステージ（Stage A / B、反復 k）、周期数、ETA。
- 収束プロット：周期統計（電極 DC 電圧、電力、代表シース電圧）と、密度反復の残差（対数）。
- ログ：ngspice メッセージ（Info / Warning / Error でフィルタ）、再試行の記録。
- ラン履歴：日時、モード、主要メトリクス、状態（成功 / 失敗 / 中止）。ダブルクリックで結果を開く。

### 4.6 結果タブ

| タブ | 内容 |
|---|---|
| 概要 | 電極ごとの $V_{dc}$、$V_1$、$I_1$、$P$、$Z$（基本波）；均一性指標 $U$、中心/エッジ比；$\lambda_{eff}$、$kR$、$\delta/(l_p/2)$；電力収支誤差；計算時間。警告一覧 |
| 径方向 | 量の複数選択（$\langle V_{sh}\rangle$、$V_{sh,1}$、$S_e$、$S_{ohm}$、$S_{stoc}$、$\bar s$、$J_{z,1}$、$\Gamma_i$、$E_i$、$n$ …）、上下シースの切替、対数軸、領域境界マーカ、正規化（中心値 / 平均値）表示 |
| 2D マップ | $p_{ohm}(r,z)$、$|J_r|$、$|J_z|$、$|B_\phi|$ の擬似カラー。幾何（層・電極）とシース境界 $z_s(r)$ を重畳。カラーマップ・範囲の指定 |
| 波形 | ノード・ブランチの選択（ツリー：電極 / セル / 層）、時間窓、重ね描き、カーソル読み取り |
| スペクトル | 選択量の高調波（棒グラフ＋表）、PSR 指標 |
| エッジ | ウェハエッジ ± 30 mm の拡大：$\langle V_{sh}\rangle$、$\bar s$、$z_s$、$\theta$。FR 側との段差の数値表示 |
| 密度（SC） | 反復ごとの $n(r)$ 重ね描き、$T_e$、残差履歴 |
| 比較 | ラン履歴から複数選択し同一量を重ね描き、差分表示、凡例にパラメータ差分を自動表記 |
| スイープ | 1D：メトリクス vs パラメータ（複数メトリクス）；2D：ヒートマップ。点をクリックで該当ランを開く |

## 5. プロット仕様

- pyqtgraph（OpenGL 任意）。$10^6$ 点までパン/ズームが滑らか（自動ダウンサンプリング）。
- 量ごとに固定色（設定可）。軸ラベルに単位。クロスヘア読み取り、凡例のドラッグ、右クリックで CSV/PNG エクスポート。
- 径方向プロットには $R_w$、$R_{fr,in}$、$R_{fr,out}$ の縦線マーカを常時表示。
- 2D マップはセル中心値を双線形補間（補間 off も可）。アスペクト比は実寸比 / 自動を切替。
- 比較表示では基準ランに対する比（%）をサブプロットで表示。

## 6. 性能要件

| 項目 | 目標 |
|---|---|
| 起動（ウォーム） | < 3 s |
| パラメータ編集 → 派生量更新 | < 50 ms |
| AC プレビュー（ボタン押下 → 描画） | < 1.5 s（ワーカ起動含む） |
| UI スレッドのブロック | 50 ms 超なし（計測してログ） |
| 結果（200 MB HDF5）の読み込み | 最初の描画まで < 2 s（遅延読み込み） |
| 波形 $10^6$ 点のパン/ズーム | 30 fps 以上 |
| メモリ | 通常ケースで < 2 GB |

## 7. 操作性

- ショートカット：F5 実行、Esc 中止、Ctrl+S 保存、Ctrl+Shift+S 別名保存、Ctrl+E エクスポート、Ctrl+Z/Y Undo/Redo、Ctrl+1〜9 タブ切替。
- すべての設定変更は Undo/Redo 可。プロジェクトは自動保存（復元可）。
- ツールチップに物理的な説明と仕様書の節番号（例「01 §3.2」）を記載。
- 入力検証は即時。実行前に未解決の検証エラーがあれば実行ボタンを無効化し理由を表示。
- 最近使ったプロジェクト、テンプレートからの新規作成。

## 8. エラー・警告の表示

- ngspice の収束失敗：再試行中はステータスに表示、最終失敗時は原因候補と対処（ランプ延長、$V_{min}$、メッシュ粗さ）を提示。
- 電力収支誤差 > 1 %、周期定常未達（`cycles_max` 到達）、密度反復未収束は結果の概要タブに警告バッジ。
- ユーザ定義ネットリストの Lint エラーは該当行をハイライト。

## 9. 国際化・アクセシビリティ

- 日本語 / 英語の UI 文字列（`*.ts`）。数式記号・単位は共通。
- フォントサイズ変更、ハイコントラストテーマ、キーボード操作のみでの主要操作。
