# 05. 検証計画

## 1. 方針

- **解析解との一致**（V1〜V4, V6）で物理モデルと回路化の正しさを確認し、**定性的傾向**（V5, V8）で 2 電極構成の妥当性を確認し、
  **回帰・性能**（V7）でリリース品質を維持します。
- すべての検証ケースはプロジェクト JSON として `data/examples/validation/` に保存し、CI で自動実行します。
- 合格基準は数値で定義します。満たさない場合は原因（離散化・モデル・数値設定）を分析し、仕様か実装を改訂します。

## 2. 検証ケース

### V1 単セル均質モデル（L&L §11.2 との比較）

- 設定：$N_r = 1$、磁束チェーン無効（半径が十分小さい設定で自動的に無効化されることも確認）、上下対称（同面積、同スタック無し）、Ar 50 mTorr、$n = 10^{16}\ \mathrm{m^{-3}}$、13.56 MHz、$T_e$ 手動 3 eV。
- 確認項目と基準：
  1. 線形 PSR 周波数：AC 掃引で検出した $\omega_{PSR}$ が $\omega_{pe}\sqrt{2\bar s/l_p}$ と **2 % 以内**。
  2. シース電圧波形（matrix モデル、電流正弦波駆動、電子・イオン電流を極小に設定）：$V_{sh}(t) \propto (1-\cos\omega t)^2$ との RMS 偏差 **5 % 以内**。DC 成分 / 最大値 = 3/8 を **3 % 以内**で再現。
  3. 非対称面積（面積比 1:2, 1:4）：ブロッキング容量付きで自己バイアスが収束し、シース電圧比が matrix 則 $V_a/V_b = (A_b/A_a)^2$ と **10 % 以内**（電子・イオン電流を含むため厳密一致はしない）。
  4. 電力収支誤差 **< 1 %**。
  5. 確率的加熱：$S_{stoc}$ が $m_e n_s \bar v_e\langle u_s^2\rangle$（波形から直接計算）と **1 % 以内**（抵抗表現の整合）。

### V2 線形定在波（径方向伝送線路との比較）

- 設定：一体電極（ウェハ領域が全半径）、上部接地、外周 short、一様 $n$、AC モード、シースは線形容量（固定 $\bar s$ = 1 mm 上下）、$N_z = 1$、60 / 100 MHz、$R$ = 150 / 225 mm、$l$ = 30 mm。
- 解析解：$|V_{sh}(r)| / |V_{sh}(R)| = J_0(kr)/J_0(kR)$、$k = 2\pi/\lambda_{eff}$（01 章 §10）。
- 基準：$N_r \ge 40$ で最大相対偏差 **2 % 以内**（$kR \le 1.5$）。$N_r$ を 2 倍にしたとき偏差が約 1/4 になる（2 次精度）。
- 追加：外周 open の場合に電流分布の零点位置が解析解（$J_1$ の零点）と **2 % 以内**。

### V3 表皮効果（平板スラブ解との比較）

- 設定：$n = 10^{18}\ \mathrm{m^{-3}}$（$\delta \approx 5.3$ mm）、$l_p$ = 30 mm、AC 60 MHz、$N_z$ = 8 / 16（シース側グレーディング）、中央付近の半径で評価。
- 解析解：バルク内径方向電流密度 $J_r(z) \propto \cosh\big((z - l_p/2)/\tilde\delta\big)$、$\tilde\delta = \sqrt{1/(j\omega\mu_0\sigma_p)}$（複素）。
- 基準：減衰長（振幅の 1/e）が **10 % 以内**（層厚 $\le \delta/3$）。$n = 10^{15}$（$\delta \gg l_p$）では $N_z = 1$ と $N_z = 8$ の径方向プロファイルが **1 % 以内**で一致。

### V4 磁束チェーンの単体検証（回路レベル）

- 設定：1 つのセル境界に 3〜6 本の径方向ブランチ（任意の高さ $\zeta_j$）を置き、各ブランチに既知の正弦波電流源を流す。
- 基準：各ブランチの誘導電圧の複素振幅が $j\omega\sum_{j'} L_{jj'} I_{j'}$、$L_{jj'} = \mu_0\Delta r\min(\zeta_j,\zeta_{j'})/(2\pi r)$ と **相対 $10^{-6}$ 以内**。
- 併せて：`Q=` 容量の電荷保存（1 周期の電流積分がゼロ、相対 $10^{-6}$）、`F`/`E` の向きの規約テスト。

### V5 2 電極・FR 連成（整合性・傾向）

- 設定：代表 300 mm 構成、60 MHz、Ar 50 mTorr、$n = 10^{16}$。
- 確認項目と基準：
  1. **連続性**：FR 電極を W に `tie` し、FR スタックをウェハと同一にした場合、$R_w$ をまたぐ全プロファイルが滑らか（隣接セル差が内部セル差の 2 倍以内）。
  2. **向き**：FR を `none`（開放）にすると、FR 上の $\langle V_{sh}\rangle$ が低下し、ウェハエッジ 10 mm 内の $\bar s$ の径方向勾配（$|\theta|$）が増大する。
  3. **調整性**：`cap_to_gnd` の $C$ を掃引すると、FR 上の $\langle V_{sh}\rangle$ が単調に変化し、ある $C$ でウェハ上との段差が最小になる（最小の存在）。
  4. **電力収支誤差** < 1 %、周期定常到達。
  5. **メッシュ収束**：ウェハエッジ付近の分割を 2 倍にしても、$U$ と $\theta_{max}$ の変化が 5 % 以内。

### V6 密度反復（Phase 2、全体モデルとの比較）

- 設定：電磁効果が無視できる条件（13.56 MHz、$R$ = 100 mm）、一様初期密度。
- 基準：
  1. 収束後の $n_0$（径方向平均）が Lieberman 全体モデル（電子側パワーバランス）と **5 % 以内**。
  2. 既定の緩和係数で 30 反復以内に収束。初期値を 1/3 倍・3 倍にしても同じ解に **$10^{-3}$ 以内**で収束。
  3. 60 MHz・$R$ = 150 mm では中心高の $S_e(r)$ に対応して中心高の $n(r)$ が得られ、拡散により $S_e$ より平坦（$U_n < U_{S_e}$）。

### V7 回帰・性能

- 例題プロジェクト（代表構成、V1〜V5）のゴールデン結果と比較：AC 量は相対 $10^{-6}$、TRAN メトリクスは相対 $10^{-3}$ 以内。
- 計算時間が 02 章 §7 の予算内（Windows ランナーで計測し履歴をグラフ化）。
- ngspice 版更新時に全ケースを再実行し、差異を記録。

### V8 文献との定性比較

- Lieberman ら 2002 / Perret ら 2003：周波数を 13.56 → 60 → 100 MHz と上げると中心/エッジ比が単調に増大し、$kR$ が 0.5 を超える付近から 10 % 以上の不均一になる。
- 高密度側で表皮効果によるエッジ高成分が現れ、周波数・密度平面上で均一性が極小となる領域が存在する（Chabert 2007 の議論）。
- 低圧・非対称条件で $V_{sh}$ に PSR 由来の高調波が現れる（Mussenbrock–Brinkmann）。
- これらは「傾向の一致」を確認するもので、数値基準は設けません。結果はドキュメント化します。
