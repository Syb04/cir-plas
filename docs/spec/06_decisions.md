# 06. 決めていただきたい事項と暫定仮定

本章の回答を反映して仕様 v0.2 を確定し、実装（07 章 M1）に着手します。
各項目に **推奨案**を併記しています。「推奨でよい」とだけ回答いただければ、その通りに進めます。

## 1. 質問（優先度順）

### Q1. 技術スタック（GUI とコアの実装言語）

| 選択肢 | 概要 | 向いているケース |
|---|---|---|
| **A. Python 3.12 + PySide6 + pyqtgraph（推奨）** | ネイティブ Qt GUI。計算は ngspice と numpy。スクリプトから同じコアを呼べる | 物理モデルを頻繁に改良する、スイープ/自動化を多用する、開発速度を優先 |
| B. C++20 + Qt 6 | 最速・単一 exe。開発工数 2〜3 倍 | 多数のユーザに配布する、起動 1 秒未満が必須、Python 環境を置けない |
| C. C# .NET 8 + WPF | Windows に最適化。Linux で GUI をテストできない | 社内が .NET 中心 |

- 推奨 A の根拠と「速さ」の担保は 03 章 §1。A を選んでも、コア（ワーカ CLI ＋ HDF5）の境界は固定するので、後から GUI だけ B に置き換え可能です。
- **確認事項**：利用 PC に Python 実行環境（同梱配布）を置いて問題ないか。

### Q3. FR 電極の駆動方式（v1 で検証対象にするもの）

テンプレートは全種類（独立電源 / 接地への可変 C / 直列 LC / ウェハ電極との結合 / DC / 開放 / 短絡）を用意します。
**検証（05 章 V5）とデフォルト GUI の中心に据える方式**を 1〜2 つ選んでください。

- 推奨：**独立電源（同周波数・位相振幅可変）** と **接地への可変 C** の 2 つ。

### Q4. ガス種と圧力範囲

- 推奨：v1 は **Ar のみ**（L&L の反応速度係数で $T_e$、$\varepsilon_c$、$\nu_m$ を計算）。圧力 5–200 mTorr。
- O$_2$、CF$_4$、混合ガス等を v1 から必要とする場合、反応速度係数（または断面積）データの入手元を教えてください。データファイル形式で追加できる設計にします。
- 高圧側（数百 mTorr 以上）を主対象とする場合は、衝突性シースのイオン流束補正を v1 に繰り入れます。

### Q5. 外部回路のモデル化範囲

- 推奨 v1：**理想電圧源（多周波・位相）＋ ブロッキング容量 ＋ 給電インダクタンス ＋ ストレイ容量 ＋ FR 調整回路 ＋ ユーザ定義ネットリスト**。
- v2：50 Ω 発振器 ＋ 整合器（L 型/π 型、自動チューニング）、電力指定駆動、ケーブル（伝送線路）。
- 実機の整合器構成や、電極〜整合器間の寄生成分の概略値をお持ちであれば、デフォルト値に反映します。

### Q6. 電子密度の自己無撞着計算のタイミング

- 推奨：**v1 は密度分布を与える（Level 0）**、**v2 で自己無撞着（Level 1）**。
  理由：Level 0 でも「与えた密度の下での加熱分布と FR 調整の効果」は評価でき、まず回路化と電磁効果の検証を固めたいため。
- 最初から Level 1 を最優先にする場合は、M4 と M5 の順序を入れ替えます（07 章）。

## 2. 暫定仮定（回答がなければこのまま進めます）

1. 軸対称 (r, z)。方位角方向の非一様性は扱わない。
2. 電子はマクスウェル分布、$T_e$ は空間一様（粒子バランスで決定）。
3. イオン密度は RF 周期内で一定。密度は軸方向一様、$h_l$ でシース端密度を補正。
4. シースは準静的 $s(V)$ 関係（matrix 既定、Child 選択可）、確率的加熱は hard-wall 抵抗表現。
5. 誘電体・半導体層は線形（$\varepsilon_r$、$\sigma$ 一定）。ドープ Si は $\sigma$ を与えて導体的に扱う。
6. 磁束チェーンの高さは公称値。シース厚の時間変動による磁束再配分は無視。
7. 外部回路は線形集中定数。ユーザ定義ネットリストで任意の SPICE 要素を追加可。
8. 解析時間の目標は 02 章 §7。超過時は保存ベクトル削減 → XSPICE コードモデル化の順で対処。
9. 開発は Linux CI で単体〜GUI スモークまで自動化し、Windows でパッケージ・検証を行う。
