# CirPlas 仕様書（v0.1 ドラフト）

**CirPlas**（仮称）は、半導体エッチング用 CCP（容量結合プラズマ）装置を対象に、
ウェハ電極とフォーカスリング（FR）電極の **2 つの駆動電極** を持つ軸対称な放電空間を
**回路網（等価回路メッシュ）** として表現し、**ngspice** で解くことで

1. 径方向の電子加熱分布（オーミック加熱・確率的加熱）
2. その結果としての電子密度分布（自己無撞着反復）

を計算する、プラズマ専用の回路シミュレータです。定在波効果と表皮効果を
回路要素（磁束チェーン）として取り込み、Windows 上でネイティブに高速動作する
デスクトップ GUI を備えます。

## 状態

- 版: **v0.2**（2026-10-29）。v0.1 ドラフトに対する回答（[06_decisions.md](06_decisions.md)）を反映し、実装（07 章 M1）に着手した版です。
- 確定した主な方針：
  - 実装言語は **Python 3.12+ / PySide6（Qt 6）**。
  - FR は **ウェハ電極と同じ電源**から、**静電チャック（ESC）の誘電体を介した容量結合**で RF を受ける構成を既定とする（独立 FR 電極はオプション）。
  - ガスは Ar、外部回路は理想電圧源＋受動素子、密度は v1 では与え v2 で自己無撞着。
  - **OSS** として公開（ライセンスは Apache-2.0 を提案中）、**日本語 UI** 既定、**インストーラ**を提供。

## 表記

- 単位は SI。電子温度 $T_e$ は eV 単位（$k_B T_e / e$ の意味）で表記します。
- 「シース電圧」はプラズマ側を正とした電位差（通常 $\geq 0$）です。
- 数式は GitHub Markdown の LaTeX 記法です。
