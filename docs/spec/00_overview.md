# 00. 概要

## 1. 背景

### 1.1 既存のプラズマ等価回路モデルの限界

CCP の等価回路モデル（Metze–Ernie–Oskam 1986、Lieberman の均質モデル、
Sobolewski の GEC セル等価回路、Mussenbrock–Brinkmann の非線形直列共鳴モデルなど）は、
放電全体を **1 組の集中定数回路**（シース容量・ダイオード・イオン電流源＋バルクの L–R）
で表し、**駆動電極は 1 つ**、**面内分布は扱わない**のが普通です。
これらは放電の全体的な電気特性（インピーダンス、自己バイアス、高調波、PSR）を
説明するには有効ですが、

- 300 mm ウェハ上の **径方向不均一**（定在波効果・表皮効果・エッジ効果）
- ウェハ電極と **フォーカスリング（FR）電極** の 2 系統駆動とその結合
- FR のインピーダンス調整やシース境界の傾きといった **エッジ制御**

を議論できません。一方、流体・PIC シミュレーション（HPEM、VizGlow、PIC/MCC 等）は
これらを扱えますが、計算コストが大きく、回路（整合器・ストレイ容量・FR 調整回路）との
連成も容易ではありません。

### 1.2 本ツールの狙い

本ツールは両者の中間に位置づけ、

- **放電空間を軸対称 (r, z) の回路メッシュに分割**し、各セルを物理に基づく
  等価回路要素（非線形シース、Drude バルク、誘電体層）で表す
- セル間の磁気結合（ファラデーの法則）を **磁束チェーン**として回路化し、
  **定在波効果**と**表皮効果**を回路の中で自然に再現する
- 外部回路（電源、ブロッキング容量、ストレイ容量、FR 調整回路、整合器）を
  **同じネットリスト上**で接続する
- 得られた電流・電圧波形から **電子加熱の径方向分布**を算出し、
  局所パワーバランスと径方向拡散で **電子密度分布**を自己無撞着に求める

ことを目的とします。ソルバは実績のある **ngspice** を用い、
GUI は **Windows ネイティブ・非 Web** で高速に動作するものとします。

## 2. 対象装置

### 2.1 代表構成（デフォルトプロジェクト）

```
                 上部電極（接地 or VHF 駆動）/ Si プレート
   ┌─────────────────────────────────────────────────────────────┐ z = l
   │                                                             │
   │          バルクプラズマ（Drude 媒質: L_e, R_e, C）              │
   │                                                             │
   ├ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ~ ┤  ← 下部シース（非線形）
   │ Si ウェハ (300 mm)         │ FR (Si/SiC/石英) │ カバーリング │
   ├────────────────────────────┼─────────────────┼─────────────┤
   │ ESC セラミック             │ 結合リング(誘電体)│             │
   ├────────────────────────────┼─────────────────┼─────────────┤
   │ ウェハ電極 (ESC ベース)     │ FR 電極          │ 接地シールド │
   └────────────┬───────────────┴────────┬────────┴─────────────┘ z = 0
                │ RF1 (+LF)              │ RF2 / 可変 C / DC / 開放
   r = 0                             r = R_w  r = R_fr       r = R_wall
```

- **軸対称**（方位角方向の変化は扱わない）
- 下部構造は半径方向に **ウェハ領域 / FR 領域 / 外周（カバーリング・接地シールド）領域** に分かれ、
  各領域は「導体電極 ＋ 誘電体（または半導体）スタック ＋ シース」で構成
- 下部の **2 つの駆動電極**：ウェハ電極（ESC 内部電極）と FR 電極
- 上部電極：接地、または独立駆動（VHF）を選択可能
- 外周の境界：チャンバ壁（短絡）／誘電体コンファインメント（開放）／任意インピーダンス

### 2.2 代表パラメータ（暫定・要確認 → 06 章）

| 項目 | 暫定値 |
|---|---|
| ウェハ径 | 300 mm（$R_w$ = 150 mm） |
| FR 内径 / 外径 / 厚さ | 151 mm / 180 mm / 4 mm（Si） |
| ESC セラミック | Al$_2$O$_3$ 相当、$\varepsilon_r$ = 9.5、厚さ 1 mm |
| ギャップ（ウェハ面–上部電極） | 30 mm（径方向プロファイル指定可） |
| チャンバ（接地）半径 | 250 mm |
| 周波数 | 60 MHz（ウェハ電極）、FR は同周波数で位相・振幅可変、LF 2 MHz を重畳可 |
| ガス / 圧力 | Ar、20–100 mTorr |
| 電子密度 | $10^{15}$–$10^{17}$ m$^{-3}$ |

## 4. スコープ

### 4.1 Phase 1（v1.0）

- 軸対称 (r, z) 回路メッシュ生成：径方向任意分割、バルク軸方向 1 層以上
- 要素モデル：誘電体/半導体層（R‖C）、非線形シース（電荷ベース容量・電子電流・イオン電流・確率的抵抗）、
  Drude バルク（L–R‖C）、磁束チェーン（定在波・表皮効果）
- 2 駆動電極（ウェハ・FR）＋上部電極（接地/駆動）＋外周境界
- 外部回路：理想電圧源（多周波・位相）、ブロッキング容量、給電インダクタンス、ストレイ容量、
  FR 調整回路（接地への可変 C / 直列 LC / ウェハ電極との結合 / DC）、ユーザ定義ネットリスト挿入
- 解析モード：**AC（線形小信号、瞬時）** と **TRAN（非線形時間領域、周期定常）**
- 自己バイアス（ブロッキング容量の DC 電圧）の外側反復による高速収束
- 後処理：シース電圧（振幅・DC・高調波）、電流密度分布、電子加熱分布（オーミック：バルク/シース、確率的）、
  シース厚と境界プロファイル、電極ごとの電力・インピーダンス、不均一性指標
- 電子密度：**与える**（一様 / 放物 / テーブル / ファイル）
- GUI：幾何・プラズマ・回路・数値設定、実行監視、プロファイル・2D マップ・波形・スペクトル表示、CSV/PNG 出力
- CLI（バッチ・スイープ）と結果ファイル（HDF5）

### 4.2 Phase 2（v2.0）

- 電子密度分布の自己無撞着計算（局所電子パワーバランス＋径方向両極性拡散、$T_e$ は粒子バランス）
- バルク多層化による表皮効果の定量評価（層数の自動推奨）
- パラメトリックスイープ（1D/2D）、複数ラン比較、簡易最適化（例：FR 容量で均一性最小化）
- 発振器 50 Ω ＋整合器モデル、電力指定駆動
- イオンエネルギー分布（IEDF）の簡易推定（径方向位置ごと）

### 4.3 非スコープ（本仕様では扱わない）

- 方位角方向の非一様性（給電の非対称、スリットバルブ等）→ 将来の 3D 化は別方式が必要
- 磁場印加（MERIE）、誘導結合成分
- 中性粒子輸送・ガス加熱・化学反応・堆積/エッチングプロセス
- 二次電子放出、電子ビーム的効果、$\gamma$ モード
- ウェハエッジ直近（数 mm）の 2D 静電場構造の精密再現（傾向把握まで）

## 5. 用語

| 用語 | 意味 |
|---|---|
| CCP | Capacitively Coupled Plasma。容量結合プラズマ |
| FR | Focus Ring（エッジリング）。ウェハ外周の消耗部品。独立電極で駆動/調整されることが多い |
| ESC | Electrostatic Chuck。内部に RF 電極を持つセラミック製静電チャック |
| シース | 電極・壁近傍の電子が欠乏した層。本ツールでは非線形容量＋電流源で表す |
| バルク | 準中性のプラズマ本体。本ツールでは Drude 媒質（電子慣性 L、衝突抵抗 R） |
| 定在波効果 | ギャップ内を径方向に伝搬する波の波長が電極寸法に近づき、中心高の電圧分布となる効果 |
| 表皮効果 | 高密度時に RF 電流がバルク表層（表皮深さ $\delta$）に集中し、エッジ高の加熱分布をもたらす効果 |
| PSR | Plasma Series Resonance。シース容量とバルク電子慣性の直列共鳴 |
| 磁束チェーン | 本ツール独自の呼称。ファラデー起電力を表す補助インダクタ列（01 章 §4） |
| 自己バイアス | ブロッキング容量を介した駆動電極に生じる DC 電圧 |
| 周期定常 | RF 周期ごとの平均量が変化しなくなった状態 |
| ランナ / ワーカ | ngspice を実行する別プロセス（03 章） |
