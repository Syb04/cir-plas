## フェーズ間の依存関係

```
M0 ─► M1 ─► M2 ─► M3 ─► M4 (v1.0) ─► M5 (v2.0) ─► M6
                 └─ GUI 骨格は M2 から並行して育てる
```

- 06 章の決定により、密度の自己無撞着計算は M5（v2.0）、インストーラは M4（v1.0）の成果物です。
