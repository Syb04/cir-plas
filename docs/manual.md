# CirPlas ユーザマニュアル

CirPlas は、ウェハ電極とフォーカスリング（FR）を持つ CCP 装置を軸対称の等価回路メッシュとして ngspice で解き、
定在波効果・表皮効果を含む電子加熱分布と電子密度分布を計算するツールです。物理モデルの詳細は
[仕様書 01 章](spec/01_physics_model.md)、解析の流れは [02 章](spec/02_solver_pipeline.md) を参照してください。

## 1. インストール

### Windows（配布パッケージ）
1. インストーラは GitHub の CI 成果物として配布しています（[入手方法](../README.md#インストーラwindows)）。
   `CirPlas-<version>-setup.exe` を実行し、指示に従ってインストールします（ngspice を含むすべての依存物が同梱されています）。
2. スタートメニューの「CirPlas」を起動します。`.cirplas.json` ファイルをダブルクリックしても開けます。

### 開発者向け（Linux / Windows）
```bash
# ngspice（Linux: apt install ngspice libngspice0。Windows: libngspice-0.dll を PATH か CIRPLAS_NGSPICE_LIB に置くか、
#   共有ライブラリが無ければコンソール版 ngspice_con.exe（PATH または C:\Spice64\bin、CIRPLAS_NGSPICE_EXE で指定可）でバッチ実行）
python -m venv .venv && .venv/bin/pip install -e ".[gui,dev,gui-dev]"
.venv/bin/cirplas-gui                       # GUI
.venv/bin/cirplas-solve project.cirplas.json -o run.h5 --mode tran   # コマンドライン
.venv/bin/cirplas-sweep project.cirplas.json --param circuit.ports.W.sources.0.v --values 200,300,400 --mode ac -o sweep_out
# 2D スイープ（直積）：--param/--values を 2 組
# FR 調整の自動探索（独立 FR 電源の振幅で段差を最小化）
.venv/bin/cirplas-optimize project.cirplas.json --param circuit.ports.F.sources.0.v:200:800 --objective fr_step -o best.cirplas.json --history opt.json
# HTML レポート
.venv/bin/cirplas-report run.h5 -o report.html
# インストーラ版はコンソール実行ファイル 1 つ：cirplas-solve sweep|optimize|report ... で同じ機能を呼べます
.venv/bin/cirplas-sweep project.cirplas.json --param circuit.ports.W.sources.0.v --values 150,250 --param plasma.pressure_pa --values 4,8,12 --mode sc -o sweep2d
```

## 2. GUI の構成

| 領域 | 内容 |
|---|---|
| 左ペイン「設定」（全高） | **幾何**（領域・スタック・ギャップ・上部電極・外周境界）、**プラズマ**（ガス・密度・温度・シースモデルと導出量）、**回路**（電源・ブロッキング容量・FR 給電・追加ネットリスト）、**数値設定**（メッシュ・解析モード・周期数・自己バイアス・密度反復・ngspice とオプションの上書き・計算規模と時間の見積り） |
| 中央タブ | **断面図**（領域と径方向メッシュ）、**回路図**（外部回路の図上編集、§2.1）、**ネットリスト**（生成結果の確認）、**結果**（概要・径方向・2D マップ・波形・スペクトル・エッジ・IEDF・密度）、**スイープ**、**最適化**、**比較** |
| 右ペイン「実行」（全高） | モード選択、実行/中止、進捗と残り時間、収束履歴、ログ、ラン履歴（上から順に縦に配置） |

設定は編集するたびに検証され、ステータスバーにエラーが表示されます。Ctrl+Z / Ctrl+Y で取り消し・やり直しができます。
左右のペインはドラッグで移動・フロートでき、配置は次回起動時に復元されます（「表示 → レイアウトを初期化」で既定に戻ります）。

### 2.1 回路図エディタ（中央「回路図」タブ）

外部回路を Qucs-S のように部品を置いてワイヤでつないで作ります。プラズマと電極のラダー回路は物理モデルから自動生成されるので、
電極（W、独立 FR なら F、駆動上部電極なら T）をピンに持つ「プラズマ」ブロックとして描かれます。

- **部品の配置**：ツールバーで抵抗・インダクタ・コンデンサ・RF 電源・DC 電源・接地・ネットラベルを選び、図の上でクリックすると置けます
  （続けて何個でも置けます）。右クリックまたは Ctrl+R で向きを 90° 回転、Esc で選択ツールに戻ります。
- **配線**：ワイヤツール（W キー）でピンをクリックして始め、曲がり角ごとにクリックします。別のピンやワイヤの上をクリックすると
  配線が終わります（ダブルクリック・右クリックでも終了）。Space で L 字の折れ方向を切り替え、Esc で描きかけを取り消します。
  ワイヤの端が別のワイヤの途中に乗ると T 字につながり、交点に点が付きます。同じ名前のネットラベルどうしもつながります。
- **移動・回転・削除**：選択ツールでクリックまたは範囲ドラッグで選び、ドラッグで移動します。つながっているワイヤは自動で追従します。
  Ctrl+R で回転、Delete で削除。プラズマブロックは移動だけできます。
- **値の編集**：部品を選ぶと右側に名前と値が出ます（`10n`, `2.2u`, `1.5k` のような工学表記可）。RF 電源は周波数・振幅・位相・
  電力指定の表で多周波にでき、「集計先の電極」で電源電力をどの電極の結果に計上するかを選べます（既定は最寄りの電極）。
- **チェック**：未接続のピンは赤い丸で示され、何も選んでいないときの右側欄に警告（未接続、どの電極にも届かない電源など）と、
  自己バイアスが立つ電極（直列コンデンサで直流的に接地から浮いている電極）が表示されます。
- **モード**：既存プロジェクト（表形式で外部回路を定義）では等価な回路図が表示され、図を編集した時点で回路図モードに切り替わります
  （Ctrl+Z で戻せます）。左の「回路」タブの「外部回路の定義」でも切り替えられます。回路図モードでは整合器の自動チューニングは
  使えないので、整合用の L・C は値を指定して描きます。
- **ノード名**：ネットリスト上の名前は、接地が `0`、ネットラベルが `u_<名前>`、それ以外は `sch_<番号>` です。
  「ユーザ定義ネットリスト（上級）」の追加行からはラベル名 `u_<名前>` と `W`, `F`, `T`, `0` を参照できます。
  生成結果は「ネットリスト」タブで確認できます。

### 2.2 テーマ

「表示 → テーマ」で **OS 設定に従う / ライト / ダーク** を選べます（既定は OS 設定に従う）。暖色系の落ち着いた配色で、
プロットの背景・軸・系列色も連動します。選択は設定に保存されます（Windows ではレジストリ `HKEY_CURRENT_USER\Software\CirPlas`）。

## 3. 典型的な使い方

1. **ファイル → 新規** で代表構成（300 mm、60 MHz、段付き静電チャック：フラットな基台の上の段付きセラミック板にウェハとエッジリングが載る）が読み込まれます。調整代はウェハ下のセラミック厚、エッジリング下のセラミック厚、エッジリング厚で、幾何タブのスタックで編集します。従来の結合リング構成は「ファイル → テンプレートから新規」で選べます。寸法・材料・圧力・電圧を変更します。
2. 実行モード **AC** で実行（1 秒以内）。結果タブの「径方向プロファイル」で $|V_{sh}(r)|$、$S_e(r)$ を確認し、概要の $kR$、$\delta/(l_p/2)$ で定在波・表皮効果の目安を見ます。
3. **TRAN** で非線形解析（代表構成で 1〜2 分）。自己バイアス、シース DC 電圧、高調波、電力収支が得られます。
4. **SC** で電子密度の自己無撞着解（AC 内側反復、数秒）。「密度」タブに反復履歴が出ます。電源に電力指定があれば、
   反復の中で振幅も合わせるので、得られる密度は指定電力に対応します。数値設定の「密度反復（SC）」で「TRAN で確定・補正」を
   有効にすると、収束後に TRAN を実行し、TRAN の加熱分布で密度を補正します（密度タブで TRAN 補正の反復は色を変えて表示）。
5. **スイープ** タブで、セラミック厚・エッジリング厚や RF 振幅などのパラメータを掃引し、均一性指標の変化を見ます。軸 2 を有効にすると
   2 パラメータの直積を計算してヒートマップ表示します。グラフの点（セル）をクリックするとそのランが結果タブに開きます。
   「結果を開く…」で過去のスイープの `results.json` を読み込めます。1 軸では指標を複数チェックすると重ねて表示します
   （既定では最初の点に対する比。チェックを外すと実値）。
6. **最適化** タブで調整の変数（既定はエッジリング下のセラミック厚とエッジリング厚。独立 FR 電源の振幅・位相なども可）と範囲を指定し、ウェハ端と FR の段差や
   均一性を自動で最小化します。スタック厚を変数にするときは「厚さに z_offset を連動」で表面の高さを保てます。
   中止してもそれまでの最良点が残り、「最適値をプロジェクトに適用」で取り込めます（Ctrl+Z で戻せます）。
7. **比較** タブで複数のランの径方向プロファイル（電子密度 $n$ も可）を重ねます。基準ランに対する比（%）または差を下段に表示し、
   凡例には基準ランとのパラメータの違いを自動で付記します。

## 4. 主なパラメータ

| パラメータ | 場所 | 説明 |
|---|---|---|
| 領域 `r_out`, `z_offset`, スタック | 幾何 | 内側から外側へ領域を並べます。`z_offset` は下部導体面の段差（FR 下の台座を下げて表面を揃える） |
| 上部電極の位置 | 幾何 | 基準を「基台から」にすると上部電極は固定され、セラミックやエッジリングの厚さを変えるとプラズマのギャップが変わります（段付き ESC の既定。ウェハ面のギャップは欄の下に表示）。「基準領域の表面から」では表面に追従します。上部電極は平坦 |
| 密度モデル | プラズマ | 一様 / 放物 / テーブル / ファイル。SC モードでは初期値として使われます |
| シースモデル | プラズマ | matrix（既定）または Child–Langmuir。`alpha_min` は最小シース幅（デバイ長単位） |
| 電源 | 回路 / 回路図 | 周波数・振幅・位相の表。複数行で多周波。「電力指定」列に W を入れると供給電力一定になるよう振幅を反復します |
| 発振器と整合器 | 回路 / 回路図 | 50 Ω 発振器＋L 型または π 型（C1-L-C2）整合器を挿入。自動チューニングでは AC 解のポートインピーダンスから L/C を設計します。π 型は負荷 Q を指定可（空欄で最小） |
| ガス | プラズマ | 同梱ガス名（`ar`）またはガスデータ JSON のパス。反応速度係数は Arrhenius 式・表・断面積（CSV）で与えるか、LXCat のダウンロードファイルを `"lxcat": {"file": "Xe.txt", "species": "Xe"}` で直接指定します（励起は複数準位可）。イオン–中性粒子断面積 `sigma_i_m2` は別途必要です。負イオンを含むガス（ATTACHMENT を含むセット）は扱えません |
| シースモデル（詳細） | プラズマ | matrix / Child–Langmuir / 衝突性 Child 則（高圧で $\lambda_i$ < シース幅のとき）/ 自動 |
| ngspice オプション | 数値設定 | 既定の `.options` を表示。キーと値の表で上書きし、「既定値に戻す」でまとめて元に戻せます |
| 見積り | 数値設定 | 未知数と AC / TRAN / SC の推定計算時間。このマシンで完了したランの時間で自動的に較正されます |
| 密度反復（SC） | 数値設定 | 緩和係数（自動調整の初期値）、許容値、最大反復、TRAN で確定・補正とその回数 |
| FR への給電 | 回路 / 回路図 | `esc_coupled`（既定）/ `separate`（独立電極ポート F と調整回路）。回路図の「構成」から切り替えると領域の導体・ポートも自動で整えます |
| 外部回路（回路図） | 回路図 | 部品の配置とワイヤ配線で任意の外部回路を作成（`circuit.mode = "schematic"`、`circuit.schematic`） |
| メッシュ | 数値設定 | 領域ごとの分割数と細密化、バルク層数 `N_z`（表皮効果を見るなら 4 以上） |
| 周期数・測定窓 | 数値設定 | 周期定常判定が未達なら周期数が自動で延長されます（最大周期数まで）。共有ライブラリでは定常に達した周期で計算を打ち切り、コンソール版では収束の速さから必要な周期数を見積もって延長します |

## 5. 結果の読み方

- **電子加熱面密度 $S_e$**：バルクのオーミック加熱（軸方向＋径方向）と上下シースの確率的加熱の和を面積で割ったもの。均一性指標 $(\max-\min)/(2\,\mathrm{mean})$ はウェハ領域で評価します。
- **シース DC 電圧 / RF 振幅**：導電性ウェハでは DC が面内でほぼ一定になり、RF 振幅の分布（定在波）がシース崩壊の有無を決めます。
- **電力収支誤差**：電源電力と全散逸の差。1 % 以上なら周期定常未達や許容値の問題を疑ってください。
- **残り時間**：実行ペインに経過時間と残り時間の目安が出ます（SC では密度反復の収束の速さから推定）。
- **自動保存**：未保存の変更は 60 秒ごとに自動保存され、保存せずに終了したり異常終了したりした場合は次回起動時に復元を確認します。
- **警告**：電力収支誤差 > 1 %、周期定常未達、密度反復未収束は概要タブの先頭に「⚠ 警告」として表示されます。
- **2D マップ**：$N_z>1$ のときのオーミック加熱密度と電流密度の $(r,z)$ 分布。径方向電流は中央面に対して反対称（表皮層で逆向き）になります。
- **エッジ**：ウェハ端 ±40 mm のシース境界プロファイルと傾き、シース電圧。
- **IEDF**：結果の「IEDF」タブに下部表面のイオンエネルギー分布をセルごとに表示します（既定は中心・中間・ウェハ端・外周）。
  イオンはシース電圧に通過時間 $\tau_i = 3\bar s\sqrt{M/(2e\langle V_{sh}\rangle)}$ の 1 次遅れで応答するとした減衰電位モデルで、
  低周波ほど二山（バイモーダル）が広がります。シース内での衝突は扱わず、無衝突で通過する割合 $\exp(-\bar s/\lambda_i)$ を併記します。
  径方向プロファイルの「IEDF ピーク間隔」はその分布の幅です。
- **レポート**：「ファイル → レポートを出力」（Ctrl+E）で、表示中の結果を 1 枚の HTML（図・表・入力条件入り）に書き出します。

## 6. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「timestep too small」で止まる | 数値設定のランプ周期を増やす、`pts_per_cycle` を 200 以上にする、`numerics.ngspice.options` で `reltol` を 3e-3 にする |
| 電力収支誤差が大きい | 周期数を増やす（最大周期数を上げる）、自己バイアス許容値を小さくする |
| 密度反復が振動する | 緩和係数を 0.2 程度に下げる |
| ngspice が見つからない | `numerics.ngspice.library_path` または環境変数 `CIRPLAS_NGSPICE_LIB` に共有ライブラリのパスを指定。共有ライブラリが無い場合はコンソール版実行ファイルでバッチ実行します（Windows は `ngspice_con.exe` を PATH・`C:Spice64bin` から探索。`CIRPLAS_NGSPICE_EXE` または `numerics.ngspice.executable` で指定可） |

## 7. ファイル

- 計算結果：プロジェクトファイルと同じフォルダの `runs/`。新規（未保存）のプロジェクトや、書き込めないフォルダのプロジェクトは `ドキュメント/CirPlas/runs/` に保存します。
- プロジェクト：`*.cirplas.json`（仕様書 03 章 §4.1）
- 結果：`run.h5`（HDF5、03 章 §4.2）。Python では `h5py` で直接読めます。`cirplas.gui.results_io.ResultData` が簡易リーダです。
- 実行履歴：プロジェクトと同じフォルダの `runs/<日時>_<モード>/`
