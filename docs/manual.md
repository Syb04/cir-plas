# CirPlas ユーザマニュアル（v0.1）

CirPlas は、ウェハ電極とフォーカスリング（FR）を持つ CCP 装置を軸対称の等価回路メッシュとして ngspice で解き、
定在波効果・表皮効果を含む電子加熱分布と電子密度分布を計算するツールです。物理モデルの詳細は
[仕様書 01 章](spec/01_physics_model.md)、解析の流れは [02 章](spec/02_solver_pipeline.md) を参照してください。

## 1. インストール

### Windows（配布パッケージ）
1. `CirPlas-<version>-setup.exe` を実行し、指示に従ってインストールします（ngspice を含むすべての依存物が同梱されています）。
2. スタートメニューの「CirPlas」を起動します。`.cirplas.json` ファイルをダブルクリックしても開けます。

### 開発者向け（Linux / Windows）
```bash
# ngspice 共有ライブラリ（Linux: apt install ngspice libngspice0、Windows: libngspice-0.dll を PATH か CIRPLAS_NGSPICE_LIB に）
python -m venv .venv && .venv/bin/pip install -e ".[gui,dev,gui-dev]"
.venv/bin/cirplas-gui                       # GUI
.venv/bin/cirplas-solve project.cirplas.json -o run.h5 --mode tran   # コマンドライン
.venv/bin/cirplas-sweep project.cirplas.json --param circuit.ports.W.sources.0.v --values 200,300,400 --mode ac -o sweep_out
```

## 2. GUI の構成

| 領域 | 内容 |
|---|---|
| 左ペイン「設定」（全高） | **幾何**（領域・スタック・ギャップ・上部電極・外周境界）、**プラズマ**（ガス・密度・温度・シースモデルと導出量）、**回路**（電源・ブロッキング容量・FR 給電・追加ネットリスト）、**数値設定**（メッシュ・解析モード・周期数・自己バイアス・ngspice） |
| 中央タブ | **断面図**（領域と径方向メッシュ）、**回路図**（外部回路の図上編集、§2.1）、**ネットリスト**（生成結果の確認）、**結果**、**スイープ**、**比較** |
| 右ペイン「実行」（全高） | モード選択、実行/中止、進捗、収束履歴、ログ、ラン履歴（上から順に縦に配置） |

設定は編集するたびに検証され、ステータスバーにエラーが表示されます。Ctrl+Z / Ctrl+Y で取り消し・やり直しができます。
左右のペインはドラッグで移動・フロートでき、配置は次回起動時に復元されます（「表示 → レイアウトを初期化」で既定に戻ります）。

### 2.1 回路図エディタ（中央「回路図」タブ）

外部回路を図で表示し、図の上で編集します。プラズマと電極のラダー回路は物理モデルから自動生成されるので 1 つのブロックとして描かれ、
その周りの要素だけが編集対象です。

- **選択と編集**：要素をクリックすると右側のプロパティ欄に値が出ます。単位付きで入力でき（`2n`, `300p` のような工学表記も可）、
  ダブルクリックで最初の入力欄にフォーカスします。変更は左の「回路」タブと同じ設定を書き換えるので常に同期し、Ctrl+Z で戻せます。
- **構成の変更**：「構成」ボタンまたは右クリックメニューで、ポートごとに「50 Ω 発振器＋L 型整合器」「給電インダクタンス L_feed」
  「ブロッキング容量 C_b」「ストレイ容量 C_stray」の有無を切り替え、電源（周波数成分）を追加できます。
  「上部電極を駆動（ポート T）」を選ぶと幾何の上部電極が駆動になりポート T（電源付き）が作られます。
  「フォーカスリングを独立電極にする（ポート F）」を選ぶと `fr` 領域の下部導体が F になり、「FR 調整回路」（開放 / W と短絡 /
  接地へ C / 直列 LC / W へ結合 C / DC バイアス / 独立電源）を選べます。独立電源ではポート F が自動で作られます。
- **ユーザ素子**：「素子を追加」で抵抗・インダクタ・コンデンサ・DC 電圧源・短絡（電流プローブ）を、ノード `W`, `F`, `T`, `0`（接地）と
  任意の中間ノード `u_1`, `u_2`, … の間に追加できます。図の下部にノードごとの横線（レール）と縦の素子として描かれます。
  これらは `circuit.extra_netlist` の行として保存され、「回路」タブの「ユーザ定義ネットリスト」にも同じ行が見えます。
  モデル定義や波形付き電源などエディタが扱えない行はそのまま保持され、テキストで編集できます。
- **削除**：要素を選んで「削除」ボタン（または右クリック）。生成要素の場合は対応する設定が「無し」（0 または未設定）に戻ります。
- **表示**：ホイールで拡大縮小、ドラッグでパン、「全体表示」で全体を収めます。

### 2.2 テーマ

「表示 → テーマ」で **OS 設定に従う / ライト / ダーク** を選べます（既定は OS 設定に従う）。暖色系の落ち着いた配色で、
プロットの背景・軸・系列色も連動します。選択は設定に保存されます（Windows ではレジストリ `HKEY_CURRENT_USER\Software\CirPlas`）。

## 3. 典型的な使い方

1. **ファイル → 新規** で代表構成（300 mm、60 MHz、FR は ESC から容量結合）が読み込まれます。寸法・材料・圧力・電圧を変更します。
2. 実行モード **AC** で実行（1 秒以内）。結果タブの「径方向プロファイル」で $|V_{sh}(r)|$、$S_e(r)$ を確認し、概要の $kR$、$\delta/(l_p/2)$ で定在波・表皮効果の目安を見ます。
3. **TRAN** で非線形解析（代表構成で 1〜2 分）。自己バイアス、シース DC 電圧、高調波、電力収支が得られます。
4. **SC** で電子密度の自己無撞着解（AC 内側反復、数秒）。「密度」タブに反復履歴が出ます。
5. **スイープ** タブで、結合リング厚や RF 振幅などのパラメータを掃引し、均一性指標の変化を見ます。
6. **比較** タブで複数のランの径方向プロファイルを重ねます。

## 4. 主なパラメータ

| パラメータ | 場所 | 説明 |
|---|---|---|
| 領域 `r_out`, `z_offset`, スタック | 幾何 | 内側から外側へ領域を並べます。`z_offset` は下部導体面の段差（FR 下の台座を下げて表面を揃える） |
| ギャップ | 幾何 | 基準領域（既定は最初の領域）の表面から上部電極側表面までの距離。上部電極は平坦 |
| 密度モデル | プラズマ | 一様 / 放物 / テーブル / ファイル。SC モードでは初期値として使われます |
| シースモデル | プラズマ | matrix（既定）または Child–Langmuir。`alpha_min` は最小シース幅（デバイ長単位） |
| 電源 | 回路 / 回路図 | 周波数・振幅・位相の表。複数行で多周波。「電力指定」列に W を入れると供給電力一定になるよう振幅を反復します |
| 発振器と整合器 | 回路 / 回路図 | 50 Ω 発振器＋L 型整合器を挿入。自動チューニングでは AC 解のポートインピーダンスから L/C を設計します |
| FR への給電 | 回路 / 回路図 | `esc_coupled`（既定）/ `separate`（独立電極ポート F と調整回路）。回路図の「構成」から切り替えると領域の導体・ポートも自動で整えます |
| 追加素子 | 回路図 / 回路 | 任意の R / L / C / DC 源を `W`, `F`, `T`, `0`, `u_*` の間に追加（`circuit.extra_netlist`） |
| メッシュ | 数値設定 | 領域ごとの分割数と細密化、バルク層数 `N_z`（表皮効果を見るなら 4 以上） |
| 周期数・測定窓 | 数値設定 | 周期定常判定が未達なら周期数が自動で延長されます（最大周期数まで） |

## 5. 結果の読み方

- **電子加熱面密度 $S_e$**：バルクのオーミック加熱（軸方向＋径方向）と上下シースの確率的加熱の和を面積で割ったもの。均一性指標 $(\max-\min)/(2\,\mathrm{mean})$ はウェハ領域で評価します。
- **シース DC 電圧 / RF 振幅**：導電性ウェハでは DC が面内でほぼ一定になり、RF 振幅の分布（定在波）がシース崩壊の有無を決めます。
- **電力収支誤差**：電源電力と全散逸の差。1 % 以上なら周期定常未達や許容値の問題を疑ってください。
- **2D マップ**：$N_z>1$ のときのオーミック加熱密度と電流密度の $(r,z)$ 分布。径方向電流は中央面に対して反対称（表皮層で逆向き）になります。
- **エッジ**：ウェハ端 ±40 mm のシース境界プロファイルと傾き、シース電圧。
- **イオンエネルギー**：径方向プロファイルの「イオン平均エネルギー」「IEDF 幅の推定」は、無衝突シースの平均エネルギー $e\langle V_{sh}\rangle$ と、RF 変調によるバイモーダル幅の近似（イオン通過時間 $\tau_i = 3\bar s\sqrt{M/(2e\langle V_{sh}\rangle)}$）です。

## 6. トラブルシューティング

| 症状 | 対処 |
|---|---|
| 「timestep too small」で止まる | 数値設定のランプ周期を増やす、`pts_per_cycle` を 200 以上にする、`numerics.ngspice.options` で `reltol` を 3e-3 にする |
| 電力収支誤差が大きい | 周期数を増やす（最大周期数を上げる）、自己バイアス許容値を小さくする |
| 密度反復が振動する | 緩和係数を 0.2 程度に下げる |
| ngspice が見つからない | `numerics.ngspice.library_path` または環境変数 `CIRPLAS_NGSPICE_LIB` に共有ライブラリのパスを指定 |
